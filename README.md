# Portfolio

A personal portfolio website built with SvelteKit, showcasing my projects, skills, and professional journey.

## Technology Stack

- **Frontend:** [SvelteKit](https://kit.svelte.dev/) + [Svelte 5](https://svelte.dev/) with TailwindCSS

## Development

```sh
make dev      # start the dev server (pnpm dev)
```

## Deployment

```sh
make build    # build the Docker image
make push     # push the image to the registry
make ship     # build and push
```
